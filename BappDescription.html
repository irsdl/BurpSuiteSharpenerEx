Sharpener adds UI customisation, tab navigation and traffic highlighting features to Burp Suite.

Features

  • Choose themes and icons to distinguish the main tool tabs.
  • Customise Repeater and Intruder tab fonts, colours and icons.
  • Copy and paste tab styles, including applying a style to tabs whose titles match a regular expression.
  • Copy, paste and rename tab titles, with numbered suffixes for duplicate pasted titles and a history of previous titles.
  • Trim long tab titles to 100 characters.
  • Jump between tabs, find titles using regular expressions, and move back and forward through tab-selection history.
  • Enable scrolling for main tool tabs and Repeater/Intruder tabs.
  • Capture screenshots of Repeater and Intruder tabs.
  • Customise keyboard shortcuts for tab actions and move focus between tab headers and the HTTP request editor.
  • Change the Burp window title and icon, with macOS Dock icon support where available.
  • Use PwnFox highlighting, with an option to retain the X-PwnFox-Color header for other tools.
  • Highlight HTTP and WebSocket traffic in Proxy using tempcolorCOLORNAME and permcolorCOLORNAME markers.
  • Highlight HTTP traffic in Logger using the same markers, including requests sent by other Burp tools. Only Proxy removes temporary markers from outgoing requests; permanent markers are retained.
  • Remember the Burp window size and position, and recover an off-screen window.

Settings

Use the Sharpener top menu for configuration, keyboard shortcuts, help and maintenance.

Unreleased Settings changes: The Sharpener top menu remains available on every supported host for quick access to UI customisation, keyboard shortcuts, help and maintenance. Supporting hosts additionally offer configuration under Settings > Extensions > Sharpener. Search Settings for Sharpener, icons, themes or shortcuts. Repeater/Intruder tab menus also offer Sharpener Settings... when the host supports opening Settings programmatically.

Settings changes apply immediately. Global settings apply across projects; the window title and icon are project settings. The separate Keyboard Shortcuts dialog uses Save to apply edits. Update checks are optional and disabled by default.

Unreleased manual highlighting limit: Logger inspection is limited to 64 KiB by default. Content-Length is only an initial request-size hint: Sharpener then checks actual whole-request size before inspecting a body. Requests that are declared or actually oversized, or have missing or ambiguous length information, use a header-only inspection view, including the URL. Responses inspect their first 64 KiB. Incorrect length headers can still cause a full host copy before an oversized body is rejected. Turn off Limit Logger inspection to 64 KiB under Manual Highlighter (Proxy and Logger) for complete inspection. Original non-Proxy traffic is unchanged; Proxy temporary-marker removal retains its existing behavior.

Keyboard Shortcuts

Open Keyboard Shortcuts from the Sharpener top menu, from the bottom of a Repeater/Intruder tab menu, or from the optional unreleased Settings panel. Each configurable action has one shortcut: click its cell, press the key combination, then choose Save. These shortcuts work within the Burp window, including while typing in an editor, so they require Ctrl, Alt, Meta or a function key. Known Burp default hotkeys and basic editing keys such as Ctrl+C and Ctrl+V are rejected; custom Burp or operating-system shortcuts may still conflict.

Default Repeater and Intruder shortcuts

  • Previous tab: Ctrl + PageUp
  • Next tab: Ctrl + PageDown
  • First tab: Alt + Home
  • Last tab: Alt + End
  • Focus tab header from the request or response editor: Alt + Up
  • Show tab menu: Ctrl + Enter
  • Find tabs by regular expression: Ctrl + Shift + F
  • Find next: F3
  • Find previous: Shift + F3
  • Back to the previously selected tab: Alt + Left
  • Forward through tab-selection history: Alt + Right
  • Copy tab title: Ctrl + Shift + C
  • Paste tab title: Ctrl + Shift + V
  • Rename tab title: F2

Fixed tab-header keys

These keys are not configurable and act only while a tab header has focus. Click a tab title or use a tab-navigation shortcut to focus it.

  • Previous tab: Left Arrow
  • Next tab: Right Arrow
  • First tab: Home
  • Last tab: End
  • Enter the HTTP request editor: Down Arrow

Fixed mouse actions on Repeater and Intruder tabs

  • Show tab menu: middle-click, or Alt + any mouse button.
  • Scroll through tabs: mouse wheel, when enabled in the tab menu.
  • Increase font size: Ctrl + mouse wheel up, when mouse-wheel actions are enabled.
  • Decrease font size: Ctrl + mouse wheel down, when mouse-wheel actions are enabled.
  • Increase font size and make bold: Ctrl + middle-click.
  • Decrease font size and make bold: Ctrl + Shift + middle-click.
  • Apply the big, red and bold style: Shift + middle-click.

Default main-window shortcut

  • Move the Burp window to the centre of the screen: Ctrl + Alt + C. This shortcut can also be changed in Keyboard Shortcuts.

Usage Tips

  • Use Down Arrow on a focused tab header to enter the request editor, and Alt + Up to return from the request or response editor.
  • Copy and paste titles with Ctrl + Shift + C and Ctrl + Shift + V. Restore a pasted title from Previous Titles in the tab menu.
  • After styling a tab, assigning the same title to another tab copies its saved style.
  • Alt + click also opens the tab menu on empty areas of the tab strip.
  • Use Debug Settings under Global Settings when investigating or reporting a problem.
  • See the project repository and GitHub Releases for changes and available jars. The BApp Store version may lag behind GitHub.
  • Sample icons are available in the repository's burpicon-sample and hacker-sample-icons directories.

Compatibility and Limitations

  • Sharpener targets current Burp Stable and Early Adopter releases, Professional and Community editions, on Windows, macOS and Linux.
  • Java 21 is required, giving a technical baseline of Burp 2024.2 or later. This does not establish compatibility with every older Burp release. Older installations can use a suitable historical jar from GitHub Releases.
  • Recorded live runs exercised earlier Windows jars with Professional Early Adopter 2026.11 and Community 2026.3.3. These are partial results; full UI, clipboard, manual and cross-platform validation remains incomplete. The unreleased Settings changes need separate host validation. See the compatibility notes for current evidence.
  • The installed Windows main/taskbar icon may remain unchanged even when unpinned. Detached-window icon handling is separate, and native icon behaviour depends on the host platform.
  • Burp UI changes can affect tab discovery and styling. Report problems on the issue tracker, including the Burp version, edition and operating system.
